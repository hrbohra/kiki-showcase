CODA · INTELLIGENCE · 10 SEPThe mutual friend, actually written.

The whole product rests on one paragraph a stranger will trust — the introduction a mutual friend could have written. In the record above it types itself out of a fixed script, theatre so the design reads without a network. Behind the real build the same paragraph is written by a language model, and the decisions there are as deliberate as any screen.

  • The prompt is built from the graph, not the vibe. One pure function turns the real overlaps, mutuals and vouch notes into a facts-only brief — use only these, invent nothing — so the model narrates evidence instead of inventing a person.
  • Live, then cached, then composed. It calls the model live; if the quota runs out it serves a saved real run; if that misses it falls back to a deterministic compose. A demo can never break, and it stays honest at each step about which one spoke.
  • It says what it cannot prove. The restraint the Trust page argues in pixels is written into the prompt itself: a shared hometown is named as common ground, never as safety, and a missing track record is stated plainly rather than dressed up.
  • The key never reaches the browser. The model is reached through a tiny server proxy with the credential held in the server’s environment — the shape the real product would ship, not a key pasted into client code.

ACT · ARCHITECTURE · FULL-STACKWhat it takes to make it real.

The screens are only half the product. Behind the demo is a real backend on Kiki’s own stack — one React Native source for iOS and web, a NestJS + Postgres API, invite-only auth, real-time messaging, and the mutual-friend AI served from the live graph. These are the decisions that hold it together.

  • The trust brain is shared, not re-implemented. The graph, similarity and trust-story logic live in one pure package (@kiki/domain) that the server and both apps import — so the demo and the real backend compute the exact same answers.
  • One schema, demo or real. Postgres models mirror the domain types 1:1; the seeded demo world and Kiki’s own imported data go through the same tables and a validated import path — point it at a staging DB and it just works.
  • Honesty is enforced server-side. The AI reads only what the graph can prove, a guard rejects any model output that leaks or refuses, and the fallback ladder means a demo never shows a broken box.
  • Frictionless demo, real security underneath. One tap enters the demo; the real invite + passwordless OTP flow sits one click away, with proper token rotation and reuse detection behind it.
  • Built to hand over. Type-safe end to end, integration-tested against a real database, with CI and a written threat model — and clean ports (voice, storage, pub/sub, LLM) so the next team can swap pieces in without a rewrite.
