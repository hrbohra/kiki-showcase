The design record · Kiki

The decisions that make Kiki real.

Kiki is a working product: one React Native source for the native iOS app and the web, a NestJS + Postgres backend, invite-only sign-in, real-time messaging, and an AI that writes each introduction from the trust graph. This page is the reasoning behind it, in order of what matters — and every decision carries its proof: a live screen you can open, a diagram of the system, or the code itself.

01 · The productIt isn’t a booking app. It’s a way of proving you are worth letting in.

Every other stay platform starts with the room and bolts trust on afterwards as a star rating. Kiki inverts it: the person comes first, the room is a consequence, and the only currency is who will put their name next to yours. That one premise decides everything below.

  • Homes are sorted by how close someone is to you in people, never by price. Degrees of separation are the ranking; the price is a detail on the card.See it: Explore — “You know Danica directly · 1st degree” sits above the price.
  • The Trust page is the product. Not a rating: a paragraph a mutual friend could have written, with every claim labelled by where it came from, and a plain statement of what Kiki cannot tell you.See it: any host → Trust. Read it as the host, then as the guest.
  • Hosting reviews describe how someone keeps their own flat — not how they treat yours. So the Trust page has a guest side, and when there is no guest evidence it says so rather than padding the page.See it: Requests → “Read their trust page” → “As a guest”.
  • Mint only ever means “someone can vouch”. One colour carries one meaning across the whole app; a third-degree pill never borrows it.

03 · The intelligenceThe mutual friend, actually written.

The whole product rests on one paragraph a stranger will trust — the introduction a mutual friend could have written. It is written live by a language model, and the decisions there are as deliberate as any screen.

AI — never breaks, never lies
flowchart TD
  Q["intro(host)"] --> G["build facts-only
prompt from graph"]
  G --> L{"live model?"}
  L -->|ok + plausible| OUT["return · cache it"]
  L -->|error / quota| C{"cached run?"}
  C -->|hit| OUT2["return cached"]
  C -->|miss| B{"baked?"}
  B -->|yes| OUT3["return baked"]
  B -->|no| CMP["deterministic compose"]
  • The prompt is built from the graph, not the vibe. One pure function turns the real overlaps, mutuals and vouch notes into a facts-only brief — use only these, invent nothing — so the model narrates evidence instead of inventing a person.
  • Live, then cached, then composed. If the quota runs out it serves a saved real run; if that misses it composes deterministically. A demo can never show a broken box, and it stays honest about which one spoke.
  • It says what it cannot prove. A shared hometown is named as common ground, never as safety; a missing track record is stated plainly. A guard rejects any output that leaks or refuses.
  • The key never reaches the browser. The model is called server-side with the credential in the server’s environment — the shape the real product ships.See it: open any host — the intro writes itself, then labels its sources.

04 · The craftWhat makes it feel native, not merely responsive.

The design handoffs specified a set of interactions that separate a demo from a build. On 16 Sep every handoff was audited against the app; what the move to the monorepo had dropped was restored, and what had never been built was built. These are the ones that carry meaning.

Decisions

Weight on the yes, nothing on the no.

Accepting a stranger into your home takes a deliberate gesture: a slide to accept whose travel is eased so the last third takes real effort, committing past 86% with a success haptic. Declining is a quiet link — Kiki never counts down and never punishes a no.

See it: Requests, on a phone.
Haptics

A tick only when something means something.

Four semantic tiers, not a buzz on every tap: a selection when a toggle or tab changes, a tap when a message sends, a medium landing when the intro finishes writing, success when a request or offer is accepted. Native goes through the Taptic engine; the web falls back to the Vibration API.

See it: on a real phone — the emulator can’t vibrate.
Trust

Read as the host, read as the guest.

Arriving from Requests you are the host, so the page opens on their guest side — how they treat someone else’s flat. Arriving from a listing you are the guest, so it opens on their hosting record. No toggle to find; the entry decides the voice.

See it: Requests → Maia → “As a guest”.
Continuity

One person, two tabs, one header.

Profile and Trust share the same hero card, back affordance and tab bar, so moving between them reads as a tab switch on one page — and every action leads somewhere real: message the host, ask the voucher, accept, decline.

See it: any host → Profile ⇄ Trust.
Motion

The list assembles itself.

Explore cards rise on a 110ms stagger with an iOS spring. One thing pulses: a slow halo on a one-step host — the only animated element on screen is the strongest trust signal.

See it: Explore — Danica.
Fit

Every phone, not one phone.

Layouts are shrinkable and wrapping rather than sized for a single device, verified from 320px up. Dates in the seeded world are relative to today, and a demo-only reset keeps the shared demo evergreen after visitors accept the seeded requests.

See it: scan the QR on any phone you have.

05 · The design systemOne palette, one type scale, twenty-two marks.

The tokens were reverse-engineered from Kiki’s own product, then corrected where they failed accessibility, and every value below is the authored one the app ships. What you see here is drawn from the same source files the app imports — not a mood board.

Colour — three accents, three meanings

Teal is trust, gold is standing, rust is cost — each accent appears only where its meaning does, so colour never needs a legend. Kiki’s original teal (#0F8D74) fails AA as text on mint at 3.66:1, so it survives only as a pressed fill; teal text uses #0E4E42 (9.6:1). The faint ink was likewise corrected from #8A9099 (3.21:1) to #626C75 (4.84:1).

Type — the system face, one scale

SF Pro on iOS, the system sans on the web. Weights top out at 700: SF at 800 is Heavy, and iOS titles are Bold — a hairline fix from the Sep 2 handoff, now applied throughout. The serif on this page is the record’s voice, not the product’s.

Space, radius, shadow

Cards carry a 5% shadow at 4/14; sheets a 12% at 10/30; a brand-tinted glow is reserved for the one primary action on a screen. The 22px card radius is the default; 24 is the profile hero only; 999 is every pill.

The Loop glyph set — 22 marks, drawn, not borrowed

Emoji that carried meaning were retired and replaced with a monoline icon language: 1.9px strokes (2.2 at chip scale, where 1.9 optically vanishes), never rendered below 16px, one accent element per mark. Four marks carry the real logo path verbatim — a filled outline that is never stroked or re-traced. The ✨ is gone from the one card whose job is credibility.
